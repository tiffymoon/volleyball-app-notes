# Volleyball Scorekeeping and Stats App
Learning &amp; decision log for a volleyball app built with Lovable

## Description
An mobile responsive app that tracks scores, team stats, and player stats for games and tournaments.

## What the app does and what problem it solves
Replace manual, error-prone paper scoresheets with digital scorekeeping where players and teeams can see their stats in a more efficient way.

## Technology
Currently building with Lovable

##Features - Key functionality you've implemented
Create and manage tournaments
Add teams and players
Assign captain/s and libero/s
Generate matches
Track score and player stats by tapping on a player and selecting action/error
Toggle court view and traditional scoresheet view
VIew player stats and leaderboards
